Shape

Items use rounded-xl, and Ink re-values --radius-xl to 32px for shell-level containers. On a 44px item the browser clamps that to 22 — so the expanded item is a full pill and the collapsed 44×44 item is a circle, as is the 36px mark. The rail spec argued for a 14px square at that width, on the grounds that a pill there reads as a circle. It does.

Resolved values
--panel / bg-surface#161618 — rail, chrome strip, cards
--bg / background#0A0A0B — the page behind the cards
--border-soft#232327 — the rail's right edge and dividers
--panel-2#202023 — unused by the rail in dark
--text-dim#A1A1AA — every resting item label
--accent-strong / primary#FAFAFA — the active pill, the mark, the bell badge
