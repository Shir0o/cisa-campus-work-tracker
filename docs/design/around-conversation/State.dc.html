ADR 0022 · one state

Reviewed, and nothing else

Seen was passive — you opened the contact. Completed was deliberate — you are finished. On Around the passive half had already stopped earning its place: the New/All filter cuts on completed, the header pill counts not-completed, and the glossary has said in plain words that "opening things never makes the number fall". Seen survived as an accent dot and a button. Both go.

Two axes, one of them vestigial

The composer already broke the invariant the code states for itself — "seen is set here and only here" — by marking seen on post. The answer is not to restore it but to stop recording a state nothing on the page reads.

Seen retired here

Set by opening the person, and — against its own rule — by posting a comment. Read by the accent dot and by My Day's pointer count. Nothing else.

Opening the contact sets it
Posting to the conversation sets it
The accent dot reads it
Existing stamps go inert and the staleness prune clears them. Never migrated.

Seen is not deleted from the product — On you keeps both axes, all four verbs, and the dot.

Reviewed the one state

The deliberate half, renamed for what the button on this page has always said. On Around the verb is always Reviewed — the other three only ever appear in On you.

The card's Reviewed button sets it
Mark all reviewed sets it, for the cards the current filter shows and no others
Undo on both, via the snackbar already on the page
Per person, server-side, agrees across phone and laptop

A glance is not the same as having dealt with someone. That is the whole reason the passive half does not survive.

Why not migrate seen → completed

It would claim on a teammate's behalf that they had worked through hundreds of people they only scrolled past — the same false claim the completion-verb table already refuses to make.

The count gets bigger

And stickier. It falls only when you review something, so a Full-timer who skims without acting watches it climb. That is the point: it measures work remaining, not pages read.

The risk, named

If the number is allowed to sit permanently high it stops being a prompt and becomes wallpaper. The fix then is to narrow what reaches Around — not to make the count decay on its own again.

The reviewed card

The existing treatment is right and stays: the card drops to a softer surface and 60% opacity. What it gains is a line saying what happened, so a dimmed card is legible as a result rather than as something switched off.

The actions go with it

A reviewed card drops its action row, exactly as a completed one does today. The conversation is still reachable — open the person — but the card has stopped asking anything of you.

Under "New", it greys in place

Then clears on the next visit, which is today's behaviour and stays. Under "All" it keeps sitting there greyed.

No second marker

No dot, no badge, no colour. The dimming is the state, and now there is only one state for it to mean.

One number, in both places

The page's pill and My Day's pointer card have been counting different things — pill on not-completed, pointer on unseen. ADR 0015 promised "the number can never disagree with the dots on the page"; it disagreed with the pill. Both now count to work through, by construction.

Not optional, not later

The moment seen stops being written, a count derived from it does not degrade — it freezes. The pointer change ships in the same PR as the merge.

"Mark all seen" becomes "Mark all reviewed"

A heavier action than it was, so it says what it does, keeps its undo, and acts only on the cards the current filter is showing — working inside ?team=yp can never silently clear campus.

The pill is unchanged

It already read "{n} to work through" and already counted the right thing. This is the pointer catching up to it, not a new number.
