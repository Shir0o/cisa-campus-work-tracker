Issue #705 · choosing the number

Short boxes decide this, not the tall one

The compose box holds a 62px input and a 38px photo row. CSS scales a radius down when two on one side exceed that side’s length, so every value above 19px collapses to a stadium on the photo row — including 24. Boxes below are drawn at their real heights; widths are cut to 186px to fit five side by side.

The recommendation
Panel 14, controls and thumbnails 10, inside the card’s existing 24. Every value is already on Ink’s scale, and the nest descends for the first time.
If you want it rounder
16 on both controls is the most that reads as a rectangle here, and it is what rounded-2xl already gives — a one-word change. It is not on the Ink scale, which is the only reason it is second.
Heights derive from Tailwind’s own type metrics: rows=2 × 20px line + p-2.5 + 1px border = 62px; py-2.5 + 16px line + 1px dashed border = 38px.
