What the narrow width decides

The two actions split rather than wrap and both clear the 44px floor. The verb fits the item — Write back on a question, I followed up on an ask, Reviewed on a new person — because “I followed up” on a card about a note would claim you texted the student.

The summary line carries the state in words, so nothing depends on the 2px edge surviving a small screen. “Encourage” is not offered on an open ask: a request to go and see someone is not a thing to react to.

This is the surface a Trainee actually lives in, which is why the notification and push half ships to both platforms at once while the worklist lands on web first — mobile still derives this column from a different module with its own read store.
