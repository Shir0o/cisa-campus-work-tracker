Ink · dark

The .dark block

Ink's dark theme is a true inversion, which Bento's never was — Bento kept violet as the fill in both themes, so --accent-on could stay white throughout. That no longer holds.

One token has to become theme-dependent

In light, the primary button is black with white text. In dark, it is white with black text. So --accent-on flips — it was #FFFFFF in both Bento blocks. Anything that hardcodes white on bg-primary instead of using text-on-primary will go invisible in dark.

There are 14 hardcoded hex values left in .tsx files and 109 raw palette classes. Those are where this will bite.

The rail cannot stay black

In light the rail is a black slab on a white page — that contrast is the whole effect. In dark the page is already #0A0A0B, so a black rail vanishes into it and the floating slab stops reading as an object at all.

It takes --panel in dark, same as every other surface, and keeps its shadow. The rail is not a special colour — it is a raised surface, and the tokens already describe that.
