Why labels, not icons only

The reference is a six-destination product. A full-timer here sees thirteen. Thirteen unlabelled glyphs is a memory test, so the rail carries labels and trades the ultra-slim look for legibility.

It also retires the More menu. PRIMARY_BY_ROLE promotes only three destinations per role and buries the other ten — a compromise the top bar's horizontal space forced. A rail has the vertical room to show all of them, grouped.
