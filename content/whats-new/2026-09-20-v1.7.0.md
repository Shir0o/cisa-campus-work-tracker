# Overview
Welcome to version 1.7.0. This release introduces in-app release companion videos, coordination doc QR codes for guests, mobile BFA tagging parity, and enhanced security protections.

## New Features
- What's New Video companion: watch key release updates in the announcement on web or follow the link on mobile
- Coordination document guest QR codes: instant QR code generation for quick guest joining on web and mobile
- [Mobile] BFA intake tag parity with web
- Multi-factor authentication (TOTP) support across web and mobile
- In-app feedback follow-up thread editing and deletion

## Security & Reliability
- Firebase App Check integration for web
- Enforced noindex headers and redacted record identifiers from published feedback URLs
- Restricted access screen for non-allowlisted accounts

## UI/UX Updates
- Auto-draft release notes workflow on release tags
- Enhanced grid responsiveness to prevent clipping on compact displays
- [Mobile] Your notes read-back view
