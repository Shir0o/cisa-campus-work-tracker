# Applications (`apps`)

## Overview
Top-level directory grouping standalone client application targets in the monorepo, currently housing the cross-platform Expo / React Native mobile application (`apps/mobile`).

## Subdirectories & Boundaries
- [mobile](./mobile/README.md): React Native / Expo cross-platform mobile application for iOS and Android, providing role-tailored experiences for campus ministers, trainees, students, and community supporters.
