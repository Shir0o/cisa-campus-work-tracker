# Firebase Functions (`firebase-functions`)

## Overview
Firebase Cloud Functions subsystem containing event triggers, background schedulers, and transport integrations for push notifications, automated Spanish/English text translations, and campus ministry reminder workflows.

## Subdirectories & Boundaries
- [src](./src/README.md): Core Cloud Functions triggers, notification transport dispatchers, Expo receipt reconcilers, Gemini-driven translation sweep schedulers, and daily/weekly staff reminder crons.
